# 🤖 Repositorio del Curso Inteligencia Artificial

Bienvenido al repositorio central de mi curso. Este espacio está destinado a almacenar y documentar todo el progreso, proyectos, actividades y evaluaciones (quizzes y parciales) realizadas a lo largo del semestre.

## 📂 Estructura del Repositorio

El repositorio se divide principalmente en dos directorios:

- [**`/Actividades`**](./Actividades/): Contiene todas las actividades prácticas, talleres y proyectos realizados durante el curso.
- [**`/Quices`**](./Quices/): Contiene los análisis, actividades calificables, evaluaciones y quizzes asignados por el profesor.
